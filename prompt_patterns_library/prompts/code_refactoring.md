# Code Refactoring Prompt Template

**Role**: Act as a senior software engineer specializing in clean code, maintainability, and performance.

**Task**: Refactor the provided [LANGUAGE] code to improve readability, structure, and efficiency without changing its existing behavior. Preserve the current functionality and explain any important design decisions. Do not introduce unnecessary dependencies.

**Input Placeholders**:
- `[LANGUAGE]`: Programming language
- `[CODE_BLOCK]`: Source code to refactor
- `[REFACTORING_REQUIREMENTS]`: Specific goals or constraints (optional)
- `[CODING_STANDARDS]`: Project coding conventions (optional)

**Expected Output**:
1. Refactored code in a code block.
2. A concise explanation of the main changes.
3. Any assumptions or behavior-preservation concerns.
4. Suggested tests to confirm that the behavior remains unchanged.
