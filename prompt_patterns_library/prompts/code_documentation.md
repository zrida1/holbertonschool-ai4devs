# Code Documentation Prompt Template

**Role**: Act as a technical writer and experienced [LANGUAGE] developer.

**Task**: Create accurate, clear documentation for the supplied code. Explain the purpose and behavior of its important classes, methods, functions, parameters, return values, and exceptions. Do not document behavior that is not evident from the code or context.

**Input Placeholders**:
- `[LANGUAGE]`: Programming language
- `[CODE_BLOCK]`: Code to document
- `[DOCUMENTATION_STYLE]`: Required format or convention (for example, Javadoc, JSDoc, or docstrings)
- `[AUDIENCE]`: Intended readers
- `[ADDITIONAL_CONTEXT]`: Relevant business or technical context (optional)

**Expected Output**:
1. Documented code using the requested documentation style.
2. Descriptions of parameters and return values.
3. Relevant exception or error conditions.
4. A short list of assumptions or unclear behavior.
