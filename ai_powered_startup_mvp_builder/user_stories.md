# User Stories – TaskMaster

## User Story 1 – Create a Task
As a user, I want to create a task with a title and description so that I can organize my work.

## User Story 2 – View Tasks
As a user, I want to view all my tasks so that I can keep track of my responsibilities.

## User Story 3 – Edit a Task
As a user, I want to edit an existing task so that I can update its information when necessary.

## User Story 4 – Delete a Task
As a user, I want to delete tasks that I no longer need so that my task list stays organized.

## User Story 5 – Set Task Priority
As a user, I want to assign Low, Medium, or High priority to each task so that I can focus on the most important work.

## User Story 6 – Set Task Deadline
As a user, I want to set a deadline for each task so that I can manage my time and complete work on schedule.

## User Story 7 – Update Task Status
As a user, I want to change a task's status to To Do, In Progress, or Completed so that I can track my progress.

## User Story 8 – AI Task Breakdown
As a user, I want the AI assistant to divide a complex task into smaller subtasks so that the work becomes easier to manage.

## User Story 9 – Search and Filter Tasks
As a user, I want to search for tasks and filter them by status or priority so that I can quickly find specific tasks.

## User Story 10 – View Progress Dashboard
As a user, I want to see the total, completed, pending, and overdue tasks on a dashboard so that I can understand my overall progress.
