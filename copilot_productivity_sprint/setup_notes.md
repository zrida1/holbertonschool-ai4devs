## 5. Setup Process

1. Installed IntelliJ IDEA.
2. Opened the IDE settings.
3. Navigated to Plugins → Marketplace.
4. Searched for GitHub Copilot.
5. Installed the GitHub Copilot plugin.
6. Restarted IntelliJ IDEA.
7. Signed in using a GitHub account.
8. Authorized GitHub Copilot to access the IDE.

## 6. Verification

- Verified that GitHub Copilot appears in the installed plugins list.
