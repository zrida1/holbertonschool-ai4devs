# User Stories: Carpool Connect

## User Story 1: User Registration and Login

**As an employee, I want to register and log in using my company email so that I can securely access the Carpool Connect platform.**

**Acceptance Criteria:**
- Users can register using a valid company email address.
- The system verifies the user's email before activating the account.
- Registered users can log in and log out securely.

**Priority**: MVP

---

## User Story 2: Create a Ride

**As a driver, I want to publish a ride with my route, departure time, and available seats so that other employees can join my trip.**

**Acceptance Criteria:**
- Drivers can enter pickup location, destination, departure date, and time.
- Drivers can specify the number of available seats.
- The system displays the published ride to other employees.

**Priority**: MVP

---

## User Story 3: Search for Available Rides

**As a passenger, I want to search for available rides based on my pickup location and destination so that I can find a suitable commute.**

**Acceptance Criteria:**
- Passengers can enter their pickup location and destination.
- The system displays rides matching the selected route and date.
- Search results show departure times and available seats.

**Priority**: MVP

---

## User Story 4: Book a Ride

**As a passenger, I want to request an available seat so that I can reserve a place in a driver's vehicle.**

**Acceptance Criteria:**
- Passengers can select an available ride and submit a booking request.
- The system prevents booking when no seats are available.
- Passengers receive confirmation when the driver accepts their request.

**Priority**: MVP

---

## User Story 5: Manage Ride Requests

**As a driver, I want to accept or reject passenger booking requests so that I can control who joins my ride.**

**Acceptance Criteria:**
- Drivers can view pending booking requests.
- Drivers can accept or reject individual requests.
- The system updates the available seat count after an accepted booking.

**Priority**: MVP

---

## User Story 6: Manage User Profile

**As an employee, I want to manage my profile and commuting preferences so that other employees can learn basic information about me before sharing a ride.**

**Acceptance Criteria:**
- Users can update their name, profile information, and contact details.
- Users can specify their preferred commuting times.
- Updated profile information is displayed to other authorized users.

**Priority**: High

---

## User Story 7: Receive Notifications

**As a user, I want to receive notifications about booking requests and ride updates so that I can stay informed about my trips.**

**Acceptance Criteria:**
- Drivers receive notifications when passengers submit booking requests.
- Passengers receive notifications when their requests are accepted or rejected.
- Users receive notifications when important ride details change.

**Priority**: High

---

## User Story 8: Rate and Review Rides

**As a passenger, I want to rate and review drivers after completing a ride so that I can help other employees choose reliable drivers.**

**Acceptance Criteria:**
- Passengers can submit a rating after a completed ride.
- Users can provide a written review along with their rating.
- The system displays average ratings on driver profiles.

**Priority**: Medium

---

## User Story 9: Monitor Company Commuting Activities

**As a company administrator, I want to view commuting statistics so that I can monitor ride-sharing participation and evaluate its environmental impact.**

**Acceptance Criteria:**
- Administrators can view the total number of shared rides.
- The system displays the number of participating employees.
- Administrators can view estimated fuel savings and carbon emission reductions.

**Priority**: Medium

---

## User Story 10: Cancel a Booking

**As a passenger, I want to cancel my ride booking so that I can free my reserved seat when my plans change.**

**Acceptance Criteria:**
- Passengers can cancel an upcoming booking.
- The system updates the available seat count after cancellation.
- The driver receives a notification about the cancellation.

**Priority**: High
